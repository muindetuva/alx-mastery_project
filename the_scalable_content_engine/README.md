# The Scalable Content Engine

This mastery project implements the relational database layer for a blogging
platform. It includes normalized users, posts, comments, tags, and post-tag
relationships; targeted indexes; more than 100 realistic seed records; join
and analytical queries; and a transaction-safe seed example.

Load the project in MySQL with `SOURCE schema.sql;` followed by
`SOURCE seed.sql;`. The query files can then be sourced independently.
